# RRIVAL — Premium Men's Wear

Premium black-and-gold men's clothing store with Express + Turso + separate admin panel.

## Deploy on Render
- Root Directory: blank
- Build Command: `npm install`
- Start Command: `npm start`

## Required environment variables
- `TURSO_DATABASE_URL`
- `TURSO_AUTH_TOKEN`
- `ADMIN_PASSWORD`

No external AI API key is required for the store chatbot.
