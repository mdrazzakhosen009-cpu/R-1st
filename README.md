# RRIVAL Premium Men's Clothing Store

Full-stack Node.js + Express + Turso ecommerce demo for the Rrival menswear brand.

## Features
- Premium black/gold responsive storefront
- 12 men's demo products
- Cart and checkout/order creation
- Order tracking API
- Admin panel for products, orders and agents
- Live About Store editor
- Instagram/Facebook/TikTok/WhatsApp links from Admin Panel
- Store-only coding/database chatbot; no AI API key required
- Demo products and agent seed on first database initialization

## Render
Root Directory: blank
Build Command: `npm install`
Start Command: `npm start`

## Environment
`TURSO_DATABASE_URL`, `TURSO_AUTH_TOKEN`, `ADMIN_PASSWORD`
